# Assets Soal Bergambar

Jika kamu ingin menyimpan hasil AI secara permanen agar tidak tergantung URL sementara, simpan file JPG di folder ini dengan nama `491.jpg` sampai `500.jpg`, lalu isi properti `image` pada soal.

URL hasil API Omegatech dapat kedaluwarsa, jadi untuk deploy produksi lebih aman memakai file lokal di folder ini. Modul AI tetap tersedia untuk membuat ulang gambar saat file lokal/URL tidak tersedia.
